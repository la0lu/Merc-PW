# 04 — QC and Submission Log

## Pre-submit checklist (from the guide)
**Codebase & setup**
- [ ] Public on GitHub, not on restricted list
- [ ] 200+ code files with real complexity
- [ ] Enterprise-grade, maintained

**Task quality**
- [ ] Production-realistic scenario
- [ ] Concrete goal with success criteria
- [ ] Touches ~5–15+ files
- [ ] Non-obvious: not one-turn, not already solved
- [ ] A senior engineer would plausibly assign it
- [ ] Hard enough to surface meaningful model differences
- [ ] Clear, testable "done"

**Tags & mode**
- [ ] Language, Task Type (one), Domain(s), Interaction Mode set
- [ ] Task type matches the actual work
- [ ] Prompt matches mode

**Rationale**
- [ ] All three answered, specific, rewritten in the author's own words, each >200 chars
